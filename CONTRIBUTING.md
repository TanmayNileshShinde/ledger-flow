# Contributing to LedgerFlow

Thank you for contributing to LedgerFlow — financial clarity for complex projects.

## Financial Calculations & Accuracy
- All financial projections, interest calculations, and aggregations must use exact arithmetic clamping to prevent floating point inaccuracies.
- Ensure Firestore query indexing adheres to strict `userId` partitioning.

## Pull Request Guidelines
- Follow React + TypeScript component separation.
- Ensure Tailwind styling remains consistent with dark-mode aesthetic.
