# Security Policy

**Ledger Flow** is a client-side personal wealth and financial simulation engine.

---

## 🔒 Security Principles

1. **Local Isolation:** All financial computations, compound interest calculations, and cashflow entries run client-side in the user's browser.
2. **Zero Financial Data Transmission:** Ledger Flow does not send bank accounts, balances, or financial details to any third-party server or cloud database.
3. **Dependency Integrity:** We regularly audit dependencies for known vulnerabilities and avoid unvetted third-party tracking libraries.
